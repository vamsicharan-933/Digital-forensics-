# Ex. No: 6 — Use Sleuth Kit to Analyze Digital Evidence

## Aim

To use **Sleuth Kit (TSK)** command-line tools to analyze disk images and recover digital evidence.

## Description

The **Sleuth Kit (TSK)** is a collection of command-line tools used to analyze disk images and recover digital evidence.

---

## Step 1: Install Sleuth Kit

### 1. Download Sleuth Kit

Download the latest Windows version of Sleuth Kit from the official website or the provided Google Drive.

### 2. Install Sleuth Kit

Run the installer and follow the installation instructions.

---

## Step 2: Acquire the Disk Image

Before analysis, obtain a disk image of the evidence.

The image can be created using tools such as **FTK Imager** or **dd**.

Supported image formats include:

- `.dd`
- `.raw`
- `.img`
- `.E01`
