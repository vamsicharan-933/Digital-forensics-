# 🔍 Ex.No.5 – Use Autopsy to Create a Case and Import Evidence

## 🎯 Aim

To use **Autopsy** to create a case, import digital evidence, analyze
the evidence, and generate a forensic report.

## 📖 Introduction

**Autopsy** is an open-source digital forensics platform used for
analyzing and extracting data from digital devices.
